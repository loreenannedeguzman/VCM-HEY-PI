# Engineering History Reference Guide

This repository package includes the curated engineering-history narratives and section completion manifest. The very large raw historical logs from the accepted submission baseline are intentionally not duplicated here to keep the repository package focused and free of unnecessary historical clutter.

The accepted baseline records these raw evidence files under `FINAL SUBMISSION VCM/03_ENGINEERING_HISTORY/reference/`:

- `AGENT_LOG.md`
- `EXPERIMENT_LOG.md`
- `PROJECT_DECISIONS.md`
- `EXAM_NOTES.md`

The curated history documents in this package preserve the E50 development narrative, experiment sequence, decision record, final freeze transition, E37 recovered-recording qualification, and E53 separation boundary.
