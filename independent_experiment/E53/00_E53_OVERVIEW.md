# E53 / VCM2 Independent Experiment Overview

## Purpose

This section documents E53/VCM2 as an independent experiment. It is retained because it provides useful experimental evidence, but it is not the final E50 deployed system and does not replace E50.

## Separation From E50

| E50 | E53 / VCM2 |
|---|---|
| Final delivery VCM system. | Independent experiment. |
| Frozen command model: E50_BG_REVISED_VOCAB_ORIGINAL_PRESERVE_E41_INIT. | Separate dataset/model investigation. |
| Deployed through the E37/E50/E40 Pi stack. | No established final Pi deployment replacing E50. |
| Final benchmark evidence belongs to E50. | Results are experimental and separate. |

## E53 Dataset Summary

The documented E53 dataset is `E53_DATASET_V1` with 24,706 rows and 20 classes: 18 operational commands plus UNKNOWN and SILENCE. The documented split is 19,553 train, 2,544 validation, and 2,609 test.

## Boundary

E53 evidence must not be used to fill E50 evidence gaps, alter E50 results, or imply that E53 became the final deployed VCM.
