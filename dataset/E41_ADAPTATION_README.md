# E41 Adaptation Documentation

The final E50 training manifest includes 230 rows identified as `e41_reconstructed_adaptation`.

This adaptation material is documented separately from the collective-derived command-model data and separately from the project-specific E37 `Hey Pi` wake-recording evidence. The reviewed package evidence does not establish that the E41 adaptation rows are Gold Dataset rows, so this repository preserves the exact term `e41_reconstructed_adaptation`.
