# VCM_BALANCED Documentation

`VCM_BALANCED` is documented as selected/balanced source material used in the E50 provenance chain, not redistributed here as raw audio.

Established values from the accepted dataset inventory:

- 15,268 training samples.
- 13,801 original samples.
- 1,467 augmented samples.

The final E50 training manifest includes 2,800 `dataset2` / `VCM_BALANCED` rows. The repository includes manifest and provenance documentation for inspection, while raw source audio remains excluded because redistribution rights are not established in the reviewed package evidence.
